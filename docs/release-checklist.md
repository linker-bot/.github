# 发布检查清单

按项目类型使用；不适用的项目记录原因。此清单不自动执行发布。

- [ ] 明确版本号、版本策略和对应提交。
- [ ] 相关构建、格式检查和测试通过，记录实际验证环境。
- [ ] 区分软件、仿真和真实设备结果，未验证组合没有标为支持。
- [ ] README 安装方式、示例和兼容说明与本版本一致。
- [ ] CHANGELOG 记录新增、修复、弃用、破坏性变更及升级步骤。
- [ ] 核对许可证、第三方声明、包内文件和资产来源。
- [ ] 核对发布包不含凭据、内部地址、私有日志或开发缓存。
- [ ] 在干净环境验证安装/构建及最小示例；硬件示例按设备说明单独验证。
- [ ] 维护者检查发布产物、版本标签和下载链接。

涉及真实设备运动或协议/固件兼容变更时，记录设备型号、固件、连接方式、测试条件和停止方式。不要把一次设备测试外推到所有设备。
