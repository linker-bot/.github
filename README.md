# Linkerbot organization resources

This repository maintains the public organization profile, shared contribution guidelines, and reference material for Linkerbot projects.

## Organization profile

- [English profile](profile/README.md)
- [中文主页](profile/README.zh-CN.md)
- [Profile artwork](profile/assets/banner.svg)

GitHub displays `profile/README.md` on the public organization overview when this repository is public.

## Community defaults

- [Contributing](CONTRIBUTING.md)
- [Code of conduct](CODE_OF_CONDUCT.md)
- [Security](SECURITY.md)
- [Support](SUPPORT.md)
- [Issue forms](ISSUE_TEMPLATE/)
- [Pull request template](PULL_REQUEST_TEMPLATE.md)

GitHub uses supported community defaults when an organization repository does not define its own corresponding files. A repository with its own issue forms or issue configuration overrides the entire default issue-template directory. Defaults are not copied into project clones.

## Repository standards and templates

- [Repository baseline](docs/repository-baseline.md)
- [Reference layouts](reference-layouts/README.md): Python, C++, ROS 2, and assets
- [README template](templates/README.template.md)
- [Compatibility template](templates/compatibility.template.md)
- [Release checklist](docs/release-checklist.md)
- [Rollout and maintenance](docs/maintaining.md)

The files under `templates/` are copyable documents; this repository is not a language-specific starter repository. Reference layouts describe recommended structures, not runnable SDKs. Project licenses, workflows, labels, ownership, and branch protection must be configured per repository; they are not inherited from this repository.
