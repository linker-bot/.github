# Getting help

## Project questions and bugs

Start with the affected repository's README, examples, compatibility notes, and existing issues. Use that repository's Issues for reproducible bugs or usage questions. If it has an enabled Discussions area, that is also a suitable place for open-ended discussion.

For Python SDK documentation, see [the documentation linked by the SDK repository](https://docs.linkerhub.work/sdk/zh-cn/). Other projects should be used with their own documented setup instructions.

Include project version/commit, operating system, dependency versions, relevant commands, and sanitized logs. For hardware, include device model, firmware version, and connection type. State whether the issue occurs on real hardware, in simulation, or both.

## Other inquiries

Visit [linkerbot.cn](https://linkerbot.cn) or contact the organization's published address, [helloworld@linkerbot.cn](mailto:helloworld@linkerbot.cn), for inquiries that do not belong in a project issue. Community replies depend on maintainer availability; this page does not promise a service-level agreement.

## Security and conduct

Follow the [security policy](https://github.com/linker-bot/.github/blob/main/SECURITY.md) for vulnerabilities and the [code of conduct](https://github.com/linker-bot/.github/blob/main/CODE_OF_CONDUCT.md) for community concerns.
